# SOK Approved Manufacturer Media

Source: SOK Energy / Kam, Sales Manager
Original email thread: "SOK Marketing Media for Elevation Storefront"
Original approved media package: `SOK Product Images.zip`
Original Drive source: https://drive.google.com/file/d/1_IUGscvqpefBDORUg2eYEnp9DsGBh1-e/view?usp=sharing

## Purpose

This directory is the durable Git source of truth for manufacturer-supplied SOK product media used by Elevation UpScales.

These files are intended to replace the prior workflow of relying on chat history, ad-hoc downloads, duplicated screenshots, or generated substitute product images.

## Operating rules

- Preserve original manufacturer files.
- Do not overwrite originals with edited/generated images.
- Put derivatives in a separate `derived/` directory.
- Prefer these assets for SOK storefront, Shopify, social, marketplace, brochure, and sales-media work where permitted.
- Continue to follow SOK MAP, branding, and channel requirements.
- Product identification must match the exact SOK model/SKU before publication.

## Provenance

Elevation requested manufacturer-approved product media for use across its website, Shopify storefront, social media, eBay, and TikTok Shop. Kam subsequently supplied the product image download linked above.

The import workflow downloads the original SOK media archive directly from that vendor-supplied Drive source, extracts it, and generates a SHA-256 manifest so future workers can verify exactly what was imported.
