# Elevation UpScales — Consolidated Production Baseline

Baseline date: 2026-08-23 (Mountain Time)

This file defines the accepted source baseline after the storefront, client-funnel, navigation, and Mission Control stabilization work completed on 2026-08-23. Future work should compare against this baseline and avoid broad rewrites of protected systems.

## Protected customer funnel

- Homepage primary CTA remains **Start a Project**.
- Canonical project intake remains **/start-a-project**.
- Customer phone / SMS number remains **208-813-4998** (`+1-208-813-4998`).
- Start a Project remains a guided decision path: Location → Service → Project → Contact → Review.
- Emergency repair keeps Call Now plus the option to continue a stored intake.
- Marketplace selling remains separate from customer service project intake.
- Solar Builder remains a separate fast-track experience and must continue updating the same Solar Lead / build reference rather than creating duplicate Leads.
- Accepted analytics headline formulas must not be changed by sub-funnel, geography, Store, Marketplace, or Work With Us events.

## Storefront baseline

### Apparel Store

- Route: **/store**
- Fourthwall remains the customer checkout destination.
- Product buttons use **Buy Now** wording.
- Full-catalog resilience remains the authoritative live-catalog path.
- Original / higher-resolution Fourthwall image URLs are preferred over transformed thumbnails when available.
- Static products remain an emergency fallback only; a partial fallback must not become the intended live catalog.

### RV & Outdoor Store

- Route: **/rv-store**
- Retired AI / RV hero imagery must not return.
- Store uses the verified eBay catalog architecture.
- Product Buy Now routing should prefer exact eBay item URLs when verified.
- RV Store HTML is no-cache / revalidate so old hero/store versions do not linger after releases.

### Global Shop navigation

Customer-facing Shop navigation should consistently expose:

1. Apparel Store
2. RV & Outdoor Store
3. Collector Series

The homepage may showcase Shop more visibly, but **Start a Project remains the primary homepage CTA**.

## Marketplace baseline

- Marketplace remains a separate browse/sell product from the Elevation-owned stores.
- Existing reviewed-listing flow, seller submission routes, liked-listing behavior, and seller-contact privacy remain protected.
- Seller paths include RVs, motorcycles, bicycles/trikes, boats/watercraft, cars/trucks, and Used Gear / Solar beta.

## Work With Us baseline

Existing stored opportunity types remain unchanged for this baseline:

- `affiliate` — creator / affiliate collaboration
- `marketing` — marketing and content
- `technician` — technician, inspector, estimator, trades and regional capability
- `investment` — strategic growth / business conversation

The existing `investment` strategic lane is now also allowed to describe:

- suppliers and vendor relationships
- RV / outdoor product partnerships
- eBay / store commerce opportunities
- local business partnerships
- strategic growth conversations

This wording expansion does **not** create a new record type or change the Work With Us submission API. A later funnel redesign may split these into clearer customer-facing lanes after this baseline is verified in production.

## Mission Control / Analytics baseline

- Notifications are protected UX and should not be removed.
- Mission Control Attention Center exposes: New Leads, Calls Due, Follow-Up Due, Won / Not in Portal, Marketplace Review, and Submission Problems.
- Leads, Solar Activity, Marketplace, Marketplace Follow-Up, Work With Us, Analytics, and System / QA remain operationally separate views over existing records.
- Store / Marketplace / Work With Us engagement events are supporting sub-funnel signals and must not be inserted into the accepted Visitor → Lead headline conversion formula.
