# Storefront Reference V2

This branch preserves the accepted 0905-05 slideshow as the fallback and layers a reversible 0905-06 presentation experiment over it. The intended runtime keeps the accepted slideshow source as `home-hero-slides-base.*` and uses the existing public `home-hero-slides.*` URLs as lightweight loaders for the V2 CSS/JS. No pricing, checkout, Hawaii, SOK routing, Worker, database, auth or supplier behavior is owned here.
