# Website Worker Management Sync Prompt

Copy/paste this into any Website / Ecommerce / storefront / checkout / deployment worker:

---

WEBSITE WORKER OVERSEER DIRECTIVE

You are working on a shared production website with multiple managers/workers. Your chat is not the source of truth.

Before editing:

- read the live Gmail Management Directory;
- read the controlling Website/Ecommerce management feed;
- read Operations coordination state;
- read every manager feed that owns truth this change depends on (Supplier/Partnership, Freight, Advertising, Finance/Legal, etc. as applicable);
- resolve current `main`, accepted production receipt/baseline, active candidate, work claims, blockers, deployment custody, and production authorization;
- check whether another worker is touching the same route, file, runtime, checkout contract, navigation shell, product data path, or release candidate.

REPORT CHECK-IN TO MANAGEMENT BEFORE SUBSTANTIVE EDITS:

WORK ID:
WEBSITE WORKER:
BASELINE / MAIN:
BRANCH / CANDIDATE:
EXACT FILE/ROUTE/SYSTEM SCOPE:
PROTECTED SCOPE:
OTHER MANAGER FEEDS CHECKED:
CURRENT ACCEPTANCE STATE:
DEPLOYMENT CUSTODY:
PRODUCTION AUTHORITY:
NEXT ACTION:

WHILE WORKING:

Update the controlling management feed after any material milestone, including:

- new candidate SHA;
- materially changed files or systems;
- scope change;
- test failure or repair;
- new preview;
- new blocker;
- manager decision affecting the task;
- visual acceptance result;
- PayPal/commerce result;
- deployment custody/authorization change.

Do not let work stack invisibly on a branch and explain it only after completion.

BEFORE STOPPING OR HANDING OFF:

Update Management with exact current candidate/branch/SHA, verified/unverified state, tests, preview/production status, blocker, rollback/baseline, next action, and deployment custody.

If visual/branding/merchandising work is involved, report separately:

FUNCTIONAL:
TECHNICAL:
SECURITY / COMMERCE:
VISUAL SCOPE:
OWNER VISUAL ACCEPTANCE:

A green technical test does not equal visual acceptance.

Do not deploy unless the current management feed explicitly grants production authority for the exact work item/candidate.

END STATE:

UPDATE MANAGEMENT FEED → LEAVE MECHANICAL HANDOFF → STOP/CONTINUE AS DIRECTED.

---
