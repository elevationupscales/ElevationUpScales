# Visual / Brand Work Prompt

Use this whenever a task includes a visual upgrade, redesign, merchandising, branding, gallery, premium presentation, showcase, or owner-approved visual reference.

---

Before implementation:

1. Read the Management Directory, Management README, Manager Feed Index and controlling work feed.
2. Identify the approved visual reference and label it `VISUAL REFERENCE — CONTROLLING` when owner-approved.
3. Extract the required visual hierarchy, product/media emphasis, approved logo/identity, spacing/readability direction, icon/use-case requirements, CTA hierarchy, exact pages in scope and explicit non-scope.
4. Check Website, Supplier/MAP, Advertising and Operations feeds for affected brand/product facts.
5. Record your Management check-in before edits.

During implementation:

- do not substitute more copy, cards, generic gradients or UI controls for the requested visual result;
- preserve exact approved logos/marks;
- use authoritative product media only;
- keep product prominence and customer hierarchy ahead of internal process explanation;
- update Management after material visual/candidate changes.

Before completion report separately:

FUNCTIONAL: PASS / FAIL / NOT VERIFIED
TECHNICAL: PASS / FAIL / NOT VERIFIED
SECURITY / COMMERCE: PASS / FAIL / NOT VERIFIED
VISUAL SCOPE: PASS / FAIL / NOT VERIFIED
OWNER VISUAL ACCEPTANCE: PASS / HOLD / NOT REQUIRED

Provide desktop/mobile review evidence when practical.

A technically green candidate is not visually accepted until the visual gate passes.

Do not deploy production before the controlling Management feed records the required owner/visual acceptance and exact deployment custody.
