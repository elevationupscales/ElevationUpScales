## Anti-Stacking Rule

Before adding work, ask:

- Is this already in progress?
- Does another worker own this scope?
- Is there already a controlling candidate?
- Do the proposed files/contracts overlap another worker?
- Has another manager issued newer direction?

If yes or uncertain, reconcile before editing.
