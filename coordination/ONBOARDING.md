# Elevation 4.3 — Worker Onboarding

If you are a new worker entering this project, do this in order:

1. Read `/ELEVATION_4_3_MASTER_STATUS.md`.
2. Read `/coordination/WORKER_PROTOCOL.md`.
3. Read active records under `/coordination/decisions/` relevant to your workstream.
4. Read the handoff named as controlling in Master Status.
5. Confirm current `main` SHA.
6. State your scope and production authorization boundary before making changes.
7. When done, create/use a receipt and return a status update.

Do not rely on an older chat summary when the repository control plane says something newer.
