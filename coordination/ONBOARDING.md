# Coding Onboarding

For normal website work:
1. read `/AGENTS.md`;
2. read `/CODING-WORKFLOW.md`;
3. use `/ANNOTATION-MAP.md` for annotation-driven edits;
4. confirm current `main`;
5. create one focused work branch;
6. use `npm run qa:fast` while iterating and `npm run qa` before preview/merge/deployment.

Do not load the old Elevation 4.3 Master Status, historical handoffs, receipts, or management packets unless the owner explicitly asks for historical investigation or a specific legacy workstream.
