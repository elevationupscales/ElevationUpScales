## Privacy boundary

This repository is public. This map intentionally excludes dealer costs, private margins, raw supplier correspondence, private carrier quotes, protected rate cards, non-public compliance packets, customer data, and private supplier evidence.

Gmail is the correspondence layer. Sent/draft/reply/bounce facts may be verified there when the task requires email work, but Gmail management records do not control supplier status. Material verified changes are reconciled back into this file or the applicable current `/operations/` record.

## State rules

- **ACTIVE / WON** — established supplier relationship.
- **ACTIVE QUALIFICATION / ONBOARDING** — reply/application/commercial qualification is in progress; do not restart cold outreach.
- **CONTACTED / WAITING** — outbound was sent; do not send a second introduction.
- **ACKNOWLEDGED / CASE OPEN** — provider has opened/routed a case; await the active case.
- **DRAFT ONLY / MANAGER REVIEW** — a current draft already exists; update/supersede it rather than creating a duplicate.
- **ROUTING FAILED / BLOCKED** — do not retry until a newly verified route exists.
- **QUALIFIED / NOT YET CONTACTED** — approved prospect for future outreach.
- **RESEARCH / CHANNEL VERIFY** — material account/channel facts still need verification before outreach.
- **BACKUP / HOLD** — preserve for a defined gap; do not prospect generically.
