## 4. Shopify-guidance tactics adopted now

### A. Technical/store audit — EXECUTE NOW

Before increasing traffic, Shopify Store Operations must maintain a bounded technical/discovery audit on the existing public catalog:

- broken product/collection/internal links;
- 404 or orphaned pages;
- mobile usability;
- product-page load/rendering issues;
- weak or duplicated title tags/meta descriptions;
- weak image alt text where accurate source-safe text can be added;
- missing internal links from collections/content into commercially important product pages;
- obvious structured-data/rich-result errors when detectable without risky theme mutation.

Theme/code defects route through the current MPM6/DEV path. Shopify Store Operations owns platform/catalog metadata that is inside its lane.

### B. Search-intent product-page optimization — EXECUTE ON CURRENT PUBLIC PRODUCTS

For priority public products, improve customer/search language without changing verified commercial facts:

- human product title;
- unique SEO title;
- unique meta description;
- product benefits and practical use cases;
- exact model/SKU where customer-relevant;
- accurate specs;
- source-correct media;
- warranty/support facts;
- verified shipping/destination language;
- clear product-detail and purchase CTA path.

Do not stuff keywords and do not replace useful product detail with generic marketing language.

Priority order:

1. products already receiving organic search landings;
2. exact SKUs already cleared for free/owned promotion;
3. products with strong approved source media and clean purchase path;
4. remaining public products after higher-value pages pass.

### C. Collection-page strategy — HIGH PRIORITY / NO NEW PRODUCTS REQUIRED

Use the **existing public catalog** to create or improve customer/search-oriented collections where the grouping is factually useful and contains enough current products.

Candidate structures should be evaluated from current catalog truth, such as:

- 12V LiFePO4 Batteries;
- 48V LiFePO4 Batteries;
- Battery Monitoring & Charging;
- RV & Trailer Essentials;
- Off-Grid Power;
- other long-tail categories supported by at least several current public products.

A collection must not blur vendor/source identity required for fulfillment. Do not activate held products just to fill a collection.

Each accepted collection should receive:

- unique customer-facing title;
- concise useful introduction;
- unique SEO title/meta description;
- internal links to relevant products/content;
- clean navigation placement only where authorized.

### D. Internal-link architecture — EXECUTE

Build useful paths between:

**COLLECTION → PRODUCT → RELATED GUIDE / FAQ → RELATED PRODUCT / COLLECTION**

Prioritize:

- important collection-to-product links;
- related-product links that are genuinely compatible/useful;
- educational content links to exact products when relevant;
- breadcrumbs/native navigation where supported.

Do not create misleading compatibility claims.

### E. Rich product/search-result readiness — AUDIT / FIX SAFE METADATA

Where Shopify/theme support exists, verify search engines can correctly understand:

- product name;
- price;
- availability state;
- image;
- product identity;
- policy/return data only after policy approval.

Do not fabricate ratings/reviews or force structured-data code changes from the Shopify worker lane.

Traffic content must answer real customer questions first and sell second.

Use current expertise/product set for topics such as:

- LiFePO4 basics and practical buying considerations;
- battery-monitor use cases;
- charge-controller selection basics;
- RV/off-grid power planning;
- Hawaii/Alaska battery-shipping education only where facts are verified and approved;

Preferred reusable format:

**ONE VERIFIED CUSTOMER QUESTION → ONE USEFUL ARTICLE/GUIDE → SHORT VIDEO/CLIP → ORGANIC SOCIAL POSTS → LINKS TO EXACT RELEVANT COLLECTION/PRODUCT → TRACKED RESULT.**

No AI-sounding filler. Content must contain specific, useful, fact-checked information.

## 6. Video / organic social handoff

Shopify Store Operations does not become the social manager.

For each traffic-ready product/collection, Shopify returns to Marketing/Social:

- exact Shopify URL;
- exact SKU/product identity;
- verified current price;
- customer value proposition;
- approved image/video assets;
- key use case;
- verified shipping limitation if material;
- UTM/source naming requirement.

Marketing/Social then executes organic Facebook, TikTok, Instagram, YouTube or other owned/permitted distribution.

Community engagement should prioritize answering real RV, off-grid, solar and battery questions rather than dropping sales links without context.

## 7. Email traffic — USE CAREFULLY AFTER CURRENT EMAIL-TRUST CLEANUP

Shopify Messaging abandoned-checkout recovery is already active and should remain the first email-conversion tool unless a newer verified issue appears.

Additional customer email must follow these controls:

- customer/marketing subscribers only; do not mix vendor/support contacts into marketing lists;
- opt-in / platform-permitted recipients only;
- segment by actual customer interest/behavior where practical;
- useful product education or exact product update, not mass generic blasts;
- one controlled campaign/send path with duplicate-send prevention;

- track sessions → cart → checkout → order.

The current vendor-email duplicate/trust incident is a reason to strengthen deduplication, not a reason to stop legitimate customer lifecycle email.

## 10. Traffic activation gate

A Shopify product or collection moves into concentrated organic promotion only when:

**EXACT PRODUCT IDENTITY → SOURCE AUTHORITY → CURRENT SELLABILITY → PRICE/MAP → EXPECTED POSITIVE CONTRIBUTION → SOURCE-CORRECT MEDIA → PRODUCT PAGE TRUST PASS → VERIFIED SHIPPING LANGUAGE/ROUTE → WORKING CART/CHECKOUT → FULFILLMENT OWNER → PROMOTE.**

If one fact is missing:

**HOLD THAT PRODUCT → CONTINUE CLEAN PRODUCTS.**

## 11. Measurement standard — TRAFFIC IS NOT THE KPI BY ITSELF

Shopify manager reporting must use a dated/time-windowed funnel by source and landing page:

**SESSIONS → PRODUCT/COLLECTION LANDING → ADD TO CART → CHECKOUT START → COMPLETED ORDER → REVENUE → ACTUAL CONTRIBUTION.**

Record where available:

- referrer/source;
- campaign/UTM;
- landing page;
- product/SKU;
- sessions;
- add-to-cart count/rate;
- checkout count/rate;
- completed orders;
- revenue/AOV;
- actual contribution after fulfillment.

Decision rule:

- **traffic up + no carts = landing/product trust problem**;
- **carts up + no checkouts = cart/checkout/shipping confidence problem**;
- **checkouts up + no orders = payment/offer/final-confidence problem**;
- **orders + positive actual contribution = scale the source/product**;
- **orders + poor/negative contribution = fix economics before scaling**.

Use Shopify Analytics source/referrer reporting and UTMs where available. GA4/Search Console may be added or reconciled through the appropriate approved analytics lane; instrumentation work must not delay P0/P1 conversion repair.
