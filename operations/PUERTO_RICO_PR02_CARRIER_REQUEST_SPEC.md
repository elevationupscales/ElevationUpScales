# Puerto Rico PR-02 — Carrier Qualification Request Specification — DRAFT ONLY

**Status:** READY FOR CARRIER-SPECIFIC COMPLETION / NOT SENT  
**Initial candidates:** Crowley LCL; TOTE / qualified consolidator  
**Initial SKUs:** SOK SK12V100PC; SOK SK48V100N  
**Quantity cases:** 1 unit and 3 units, each SKU quoted separately

## Request purpose

Obtain a complete executable mainland-origin-to-Puerto-Rico freight path for each exact battery configuration.

Do not request a booking.

Do not combine different SKU assumptions into one ambiguous rate.

## Shipment data required before send

For each exact SKU insert:

- supplier legal/shipper name;
- origin ZIP;
- manufacturer/model;
- voltage / Ah;
- Wh per battery;
- applicable transport classification;
- new / undamaged / non-recalled status;
- quantity;
- batteries per package;
- package count;
- exact carton dimensions;
- gross weight per carton;
- pallet dimensions / gross weight if applicable;
- commercial value;
- matching SDS/MSDS;
- matching UN38.3 test summary;
- packaging / terminal-protection description;
- available manufacturer/warehouse packaging evidence if required.

## Carrier questions

Request written confirmation of:

1. exact battery/configuration acceptance on the proposed Puerto Rico service;
2. LCL/consolidation eligibility at the proposed quantity;
3. whether a specific approved consolidator is required;
4. mainland receiving location;
5. separately priced origin pickup option;
6. packaging requirements;
7. required shipment marks/labels and responsibility for them;
8. required regulated-cargo declaration/document set;
9. responsible trained offeror/signatory;
10. documents required before cargo may tender;
11. receiving cutoff;
12. departure frequency;
13. planning transit range after accepted tender;
14. itemized mainland transport, ocean, regulated-cargo, origin, destination, documentation, EEI, fuel, security and other accessorial charges;
15. Guaynabo/San Juan terminal or pickup location;
16. customer delivery priced separately from terminal pickup;
17. SURI/import-release assistance, scope and fees if offered;
18. free time and storage rules;
19. residential/liftgate or delivery-area restrictions;
20. carrier liability;
21. cargo-coverage options and value evidence required;
22. claim deadlines;
23. quote validity;
24. handling if shipment review rejects or delays cargo after arrival at the receiving facility;
25. EEI/ITN information required by the carrier and filing cutoff.

## Quote format

Require a dated written quote showing:

- exact SKU/configuration assumptions;
- exact quantity/package assumptions;
- origin;
- destination;
- pickup versus delivery;
- all known charges;
- exclusions;
- validity;
- payment timing;
- document gates;
- acceptance conditions.

## External-action boundary

**CASEY APPROVAL REQUIRED BEFORE ANY QUOTE REQUEST IS SENT.**

A quote request does not authorize booking, tender, payment or movement.
