## Operating sequence

For the first Hawaii order, use:

**CUSTOMER / ORDER REQUIREMENTS**  
**→ EXACT SOK MODEL + QUANTITY**  
**→ SELECT QUALIFIED ELEVATION FREIGHT ROUTE**  
**→ CONFIRM ROUTE-SPECIFIC PALLET / PACKAGING / DG REQUIREMENTS**  
**→ ELEVATION TRANSLATES REQUIREMENTS FOR SOK**  
**→ SOK CHINO CONFIRMS / PREPARES**  
**→ FINAL ROUTE CONFIRMATION**  
**→ PAYMENT / PO / RELEASE**  
**→ FREIGHT HANDOFF**  
**→ HAWAII RECEIVING / DELIVERY / PICKUP**

Do not send a generic lithium-preparation checklist as though all carriers use identical requirements. The first-order package must be tied to the exact SKU, quantity, and selected route.

## First-order information Elevation must resolve before release

- exact SOK model
- quantity
- destination island / ZIP
- pickup vs delivery preference
- selected transportation path
- carton vs pallet configuration
- total shipment dimensions and weight
- pallet securement requirements
- short-circuit protection requirements
- required lithium / dangerous-goods marks and labels
- exact documentation required by the accepting carrier
- SDS / UN38.3 documentation required for the exact model
- shipper / consignee information
- origin handoff requirements
- Hawaii receiving / final-delivery requirements

Final dangerous-goods classification, packaging, labeling, documentation and tender remain subject to the exact manufacturer documentation and accepting carrier requirements.
