**CURRENT GIT → EXACT TIKTOK REVIEW → FIELD-BY-FIELD RECON → PRIVATE SOURCE RECOVERY → CORRECT ONLY THE WRONG/MISSING FIELD → VIDEO FIELD QA → ONE SUBMISSION → RECEIPT → RETURN TO NORMAL TIKTOK COMMERCE.**

## Evidence handling

Private evidence stays private.

Use Gmail as an authorized source-file archive/recovery surface. Git records only public-safe filenames, classifications, dates, requirements, states and receipts.

Never commit:

- government ID images;
- wholesale/sales-tax license image;
- EIN notice;
- raw address evidence;
- private tax/account identifiers;
- verification video.

## Execution steps

### 1. Live ticket recon

Open the exact TikTok review/violation record and capture privately or in public-safe notes:

- violation/review state;
- `Correction` vs `Appeal` availability;
- appeal attempt number;
- submission deadline;
- every current upload field name;
- current files shown in each field;
- required video field/status;
- current warnings/errors.

Do not make changes until this map exists.

### 2. Document-slot repair

For each field, classify:

- `CORRECT — KEEP`
- `WRONG SLOT — REPLACE`
- `DUPLICATE — REMOVE/REPLACE`
- `MISSING — ADD`
- `NOT APPLICABLE / SUPPORT REQUIRED`

Known repair target from owner observation:

- duplicate/misplaced IRS EIN evidence → reduce to one EIN submission only where requested;
- business-license evidence → use the recovered `Colorado_Wholesale_Sales_Tax_License.jpeg` where the live field requests business-license evidence.

### 3. Supporting-document QA

Use exact source only when the live field requests it:

- federal tax/EIN → IRS CP575A;
- corporation registration → Colorado Articles;
- Colorado sales-tax registration → Colorado sales-tax registration record;
- representative ID → current matching ID front/back;
- address → exact matching current proof for the address type TikTok requests;
- supplier/purchase/fulfillment → current factual records.

Never use a file merely because it is available.

### 4. Representative video repair

If the existing recording can be located and verified to meet the live requirement, upload it correctly to the dedicated video field.

If its content/quality cannot be verified, record a fresh clean video that satisfies the live ticket/current TikTok guidance before submission.

Verify the Seller Center UI visibly shows the file uploaded/attached successfully.

### 5. Pre-submit RECON gate

Before final submission verify:

- no duplicated EIN occupying unrelated slots;
- business-license field contains correct license evidence where requested;
- identity/name/address information matches Seller Center inputs;
- no false warehouse-ownership representation;
- purchase/fulfillment evidence is relevant to actual Elevation operations;
- video is in the correct field and visibly attached;
- appeal/correction window still valid;
- no prior submission result is `UNKNOWN`;
- no field still displays an unresolved yellow/error state unless the ticket permits submission with supporting evidence.

### 6. Submit once

Current owner direction authorizes the factual correction/resubmission of the existing TikTok verification review when the exact current fields have been reconciled.

Do not add a materially new legal certification, ownership claim, warehouse claim or commercial statement without owner review.

### 7. Receipt

After submission record:

- date/time;
- violation/review record;
- action used: Correction / Appeal / other exact Seller Center action;
- appeal attempt number;
- public-safe evidence categories submitted;
- video attached yes/no;
- resulting Seller Center status;
- screenshot/receipt availability privately;
- next review trigger.

## Blocker rule

A TikTok verification field blocked on one document does not stop Shopify, eBay, vendors or logistics.

Within the TikTok repair itself, hold only the exact field and continue reconciling the remaining evidence.

## Close / return path

When TikTok acknowledges the corrected submission:

**REPAIR SUBMITTED → RECEIPT → REVIEW PENDING → COMPANY OPS MONITORS STATUS → APPROVED = CLOSE REPAIR + RETURN TIKTOK TO NORMAL ECOMMERCE → REJECTED = RECON EXACT REASON / ATTEMPT COUNT / DEADLINE BEFORE ANY NEXT ACTION.**
